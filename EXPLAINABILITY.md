# Decision: how the agent decides

The agent reads the notes and picks out sentences that contain a decision or a task. It groups them by owner and drops small talk.

# Inputs: data source and input used

The only input is the meeting notes text the user pastes in. The agent does not use any outside data source or the internet.

# Limits: limitations and known issues

The agent can miss action items that are written very vaguely. It cannot check whether the notes themselves are correct.
